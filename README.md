# Cronometro-FR-FC
La forma más rápida, cómoda y precisa para medir FR y FC (etc!)

Evalúas un paciente q no tiene monitoreo? 
Con esta app tienes la forma más rápida, cómoda y precisa que conocemos para medir FR y FC 

**Como usar**
1. Selecciona FR o FC
2. Toca **inicio**
3. Cuenta 6 latidos o respiraciones 
4. Toca **detener**  
   ¡y listo! ✅ verás la FC o FR o lo q hayas elegido 

**Tip**  
También puedes medir cualquier cosa que quieras conocer su ritmo, flujo, velocidad por minuto, por ej.:  
**Otras cosas contables**  
Gotas (para gotas por minuto)  
Pasos (para pasos por minuto)  
Práctica de contar pausado desde 1001 en adelante para lograr 1 nro/segundo = 60 bpm  
etc.!

## Ecuación
Inicia cronómetro  
Cuenta n (respiraciones o latidos o gotas, etc.) (6 mínimo)  
Stop cronómetro = tiempo t

Ecuación FR FC etc. = n*60/t
